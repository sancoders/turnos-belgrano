# Turnos Belgrano

App de demostración. **Está rota a propósito** y no la usa ningún negocio real: se armó
para probar Caronte, un analizador de apps vibecodeadas.

Tiene fallas de seguridad puestas a mano, entre ellas una tabla sin permisos y una página
de administración sin contraseña. Todos los datos que carga son inventados.

No la copies, no la uses de base para nada.
